---
title: Class
categories:
  - warrior # have high stats
  - rogue # close range, high agility dealer
  - swordsman 
  - martial artist # fights barehanded
  - boxer # rare type
  - archer # remote dealer, weak to close combat
  - spearman
  - priest # reatlas, tovera, heindal, karui
  - summoner 
  - healer # a magician type that performs healing
  - sorcerer # a magician type that deals magic damage. called poison magician if using poison, and a flame magician if using flames
  - shaman # a support type magician. support shaman applies buffs and a curse shaman applies curses
  - necromancer # one-man army
  - warlock # uses cursed magic which cannot be cured with divine power. good in combo with necromancer. female warlock is a witch
  - knight # use essences only for swordsmanship & basic stats, often use aura
  - paladin # combine divine spells and weaponry. cannot use essence, need to pray for divine blessings
  - alchemist # a type of mage that can turn stones into matter
  - berserker # synergizes well with a tank, and can work as a secondary tank
  - tank # takes damage and protects the team. usually steals aggro
  - mage # casts spells. cannot use essence and do not use soul power
